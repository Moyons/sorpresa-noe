# Regalo musical

Web app móvil (PWA, sin build) para regalar una noche de musical: la persona elige musical, día, hora y planes extra, y recibe su entrada.

- Personalizar nombres, mensajes, musicales, fechas y sesiones: `config.js`
- Probar en local: `npx serve .` (o abrir `index.html`)
- Publicar: GitHub Pages (rama main, carpeta raíz). En el móvil: «Añadir a pantalla de inicio».
- Si cambias archivos de la app, sube la versión de `CACHE` en `sw.js`.
